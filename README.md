# astrbot_plugin_stock_market（群内模拟股市）

群友用虚拟资金炒股：开户、看行情、买卖、挂限价单、看新闻和走势。每个群（私聊则每个用户）
有独立账本，数据和行情都存在插件数据目录里，插件升级不丢。

## 指令

| 指令 | 说明 |
|---|---|
| `/股市 开户` | 建账户，初始资金见插件配置（默认 100,000 元） |
| `/股市 行情 [页码]` | 行情卡；`/股市 行情 ST001` 查单只 |
| `/股市 买入 ST001 100` | 市价买入 |
| `/股市 卖出 ST001 100` | 市价卖出（不支持做空） |
| `/股市 买单 ST001 100 9.50` | 限价买单，冻结资金，24 小时有效 |
| `/股市 卖单 ST001 100 12.00` | 限价卖单，冻结股份 |
| `/股市 挂单` / `/股市 撤单 1` / `/股市 成交` | 委托与成交查询 |
| `/股市 新闻` | 最近市场新闻（UTC+8） |
| `/股市 走势 ST001` | 走势图卡片 |
| `/股市 持仓` | 持仓卡：可用/冻结、市值、总资产、已实现与浮动盈亏 |
| `/股市 帮助` | 玩法说明卡 |
| `/股市 改名 ST001 星辰科技` | 管理员给股票补名字 |
| `/股市 签到` | 每天一次领资金，连续签到有加成（默认 10%/天，封顶 50%） |
| `/股市 排行 [N]` | 本群资产排行卡（可用 + 冻结 + 持仓市值） |
| `/股市 盈亏 [N]` | 赚钱榜 / 亏钱榜：按买卖盈亏（已实现 + 浮动）排序 |
| `/股市 补助` | 总资产低于补助线时领救济，默认 24 小时一次 |
| `/股市 db 1000` | 赌博：下注 X 元，回报 0～2X 均匀随机；全仓时 80% 翻倍、20% 归零 |
| `/股市 抢劫 @对方` | @ 或直接写 QQ 号；只抢可用现金，成功抢 5%～20%，失败反被抢 |
| `/股市 transfer @对方 1000` | 把自己的可用资金转给对方，免手续费，双方需已开户 |
| `/股市 give @对方 1000` | 股市管理员凭空发钱（发起人账户不变，可给自己）；**隐藏指令，不在帮助里显示** |
| `/股市 clear @对方` | 股市管理员清空目标可用资金并撤销其挂单，持仓保留；**隐藏指令，不在帮助里显示** |

## 规则

- 行情每 `round_seconds`（默认 300 秒）推进一轮，单轮涨跌 ≤ `max_change_pct`（默认 10%）。
- 买卖手续费各 `fee_rate`（默认 0.1%），按成交额向上取整到分，成本里包含买入手续费。
- 限价单达到限价时按**当时市价**成交（可能优于限价），冻结差额自动退回；到期未成交自动撤销。
- 行情不依赖后台任务：轮次由时间戳推导，有指令时惰性补算，容器重启后行情仍然连续。
- 价格上涨显示红色、下跌显示绿色，与 A 股习惯一致。

### 玩法规则

- **签到**：按 UTC+8 自然日，一天一次；连续第 N 天奖励 = 基础 × (1 + (N-1)×10%)，加成封顶 50%，断签从 1 重算。
- **补助**：总资产（可用 + 冻结 + 持仓市值）低于补助线才能领，默认 24 小时冷却。
- **盈亏榜**：盈亏 = 已实现盈亏 + 持仓浮动盈亏，只统计买卖；签到、补助、give、抢劫、db 的资金变化不计入，0 盈亏不上榜，所以它反映的是「炒股本事」而不是「谁签到多」。
- **db**：下注从可用资金扣，回报在 `0 ~ 2X` 均匀随机；下注额等于全部可用资金时沿用 DDBOT 规则——80% 拿 2X、20% 拿 0。使用系统真随机，不受行情种子影响。
- **抢劫**：只抢可用现金，目标低于 10 元不能抢；成功率 = `40 + (我的总资产 − 对方总资产)/50`（元为单位），夹在 25%～75%；成功抢走 5%～20%，失败反被抢同样比例；每人每群 10 分钟冷却。
- **transfer / give / clear**（对应 DDBOT 的 `transfer`、`give`、`clear` 三个模板）：`transfer` 从自己可用资金扣、对方加，免手续费，双方都必须已开户；`give` 是管理员凭空发放，不扣发起人；`clear` 同样是管理员操作，把目标可用资金清零并撤销其挂单（冻结资金一并作废），**持仓不清**——股市资产里股票占大头，强行按市价清仓没有依据。
- **股市管理员名单**：`market_admins`（插件配置项，**默认空列表**，部署后需自己填 QQ 号），**只对 give / clear 生效**，与 AstrBot 的 `admins_id`、群主、群管理身份完全独立——即使对方是 AstrBot 管理员，不在名单里也不能用。留空表示这两个指令谁都用不了。`/股市 改名` 仍按 AstrBot 管理员身份判断。
- 排行榜昵称取自群名片（指令触发时刷新），拿不到就显示 QQ 号。

## 数据与配置

- 数据：`data/plugin_data/astrbot_plugin_stock_market/groups/<群号或 private_用户>.json`（账户里额外记录昵称、签到日期/连续天数、上次补助与抢劫时间）
- 股票名称：`data/plugin_data/astrbot_plugin_stock_market/names.json`（**所有群共用**，`/股市 改名` 后各群下一次指令即生效；价格、账户、挂单、新闻仍按群独立）
- 渲染缓存：`data/plugin_data/astrbot_plugin_stock_market/cache/`（自动清理）
- 可选背景图：把 `bg.jpg` / `bg.png` 放进插件目录的 `assets/`，卡片会自动叠加。
- 配置项见 `_conf_schema.json`，可在 AstrBot 的插件配置页直接改。

## AI 辅助创作说明

本插件是 AI 辅助创作的产物，具体情况如下：

- **需求与验收**：玩法设计、功能取舍、数值规则（手续费、签到加成、抢劫概率等）以及线上部署，均由作者决定并逐项验收。
- **代码与文档**：在 AI 编程助手（Claude，Anthropic）协助下编写，生成后经作者审查、修改与测试。
- **测试情况**：引擎层 32 项单元测试（`python tests/test_engine.py`）与容器内冒烟测试均通过；作者在自建 AstrBot（QQ / aiocqhttp 适配器）实例上实际运行。
- **已知局限**：只在 aiocqhttp 适配器上验证过，其他平台未测试；卡片渲染依赖系统中文字体（内置 Noto / 微软雅黑 / 苹方回退）。
- **风险提示**：AI 生成的代码可能存在未覆盖的边界情况，建议先在小群试用；发现问题欢迎提 issue。

本插件全部为虚拟货币玩法，与真实证券交易无关，不构成任何投资建议。
