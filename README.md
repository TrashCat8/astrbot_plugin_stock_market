# astrbot_plugin_stock_market（群内股市 · 真实行情 + 外汇）

群友用虚拟资金炒股：开户、看行情、买卖、挂限价单、加杠杆，行情直接接入**腾讯股票**与
**新浪外汇**的真实报价，A 股 / 港股 / 美股 / 人民币外汇同场交易。每个群（私聊则每个用户）
有独立账本，数据和行情都存在插件数据目录里，插件升级不丢。

- **真实行情**：默认 `data_source=real`，价格、昨收、开高低、当日涨跌全部来自实时接口；
  接口不可用时沿用上一帧报价并降级告警，交易指令不会因为断网失败。
- **外汇**：`FX_USDCNY` / `FX_EURCNY` / `FX_JPYCNY` 等 6 个货币对，可市价买卖、挂限价单、
  加杠杆，报价精确到 6 位小数（0.041805 这种日元价也不会被整数分精度吃掉）。
- **全市场按需接入**：A 股 / 港股 / 美股任意代码（`sh601988`、`sz300750`、`hk00700`、`usAAPL`，
  或裸数字 `601988`），以及 12 个主要指数（`上证` `深证成指` `创业板指` `沪深300` `中证500`
  `上证50` `科创50` `恒生` `国企指数` `纳指` `道指` `标普500`）。买过 / 查过的品种才会进账本，
  行情请求只发这些品种，不拉全市场。
- **消息交互**：行情 / 持仓 / 帮助卡片下方附带可点击按钮（行情、汇市、持仓、签到、排行…），
  点击等价于发一条对应指令；QQ 官方机器人的文字回复还会附带可点指令链，点一下就把
  `/股市 行情 1` 填进输入框。按钮需要 AstrBot >= 4.29.4，老版本自动退回纯文字。
- **离线兜底**：`data_source=simulated` 保留原版按轮次的确定性随机游走，供断网环境与单元测试使用。

## 自然语言游玩（LLM 工具）

插件向 AstrBot 的 agent 注册了 7 个 function-calling 工具，群友直接说「茅台现在多少钱」
「帮我买 100 股平安银行」「我赚了多少」就能让模型调用工具完成：

| 工具 | 用途 | 主要参数 |
|---|---|---|
| `stock_market` | 股票/外汇行情、单品种详情 | `market`（stock/fx/all）、`keyword`、`page` |
| `stock_account` | 账户概览、杠杆、挂单、成交 | `view`（overview/leverage/orders/trades） |
| `stock_trade` | 市价买卖、限价挂单、融资买入 | `action`、`code`、`shares`、`price`、`leverage` |
| `stock_repay` | 偿还融资欠款 | `amount`（0=全部） |
| `stock_play` | 签到/补助/排行/盈亏/异动/赌博/抢劫/转账 | `action`、`amount`、`target` |
| `stock_chart` | 走势区间摘要 | `code` |
| `stock_help` | 玩法与规则简述 | 无 |

工具返回纯文本摘要（现价、数量、金额、盈亏），由模型转述给群友；下单会走和指令完全相同的
引擎路径（手续费、杠杆、强平、账本一致）。工具需要模型开启 function calling，且在 AstrBot
的 provider 配置里启用工具调用；老版本 AstrBot 没有 `filter.llm_tool` 时这组工具自动不注册。

## 消息交互（按钮 / 文字指令链）

对应 QQ 机器人 API v2「消息交互」：按钮走 `keyboard` 字段，点击后平台推 `INTERACTION_CREATE`；
文字链走 Markdown 里的 `<qqbot-cmd-input>` 标签。**买卖可以点按钮直接下单**：点数量按钮 →
确认面板（显示现价与预计金额）→ 确认成交。带着对象/金额的玩法类操作（抢劫、转账、db）
仍然落到指令链上，点一下把命令填进输入框再改。

- **一级导航**（行情 / 持仓 / 帮助卡片底部）：`行情` `汇市` `持仓` `交易` `玩法`，点一下等于发对应指令。
- **品种面板固定 11 个股票**：优先放群友当前持仓，不足的用默认池补齐；买其它股票 / 指数用自然语言（LLM 工具）或直接发指令。
- **交易面板**（点「交易」）：`买入` `卖出` `买单` `卖单` `融资` + `挂单` `成交` `杠杆` `还债` `返回`。
  点 `买入`/`卖出` 直接列出品种（持仓优先，最多 10 个），点品种进入该品种的下单面板。
- **玩法面板**（点「玩法」）：`签到` `补助` `排行` `盈亏` `异动` 直接执行；
  `db` `抢劫` `转账` 回指令链（补金额或 @ 对象），`帮助` `返回` 用于翻页。
- **品种详情**（`/股市 行情 SH600519` 等）与品种选择面板：`买100` `买500` `卖100` `卖全部` `返回`，
  点数量按钮弹出确认（现价、预计支出/到账、手续费），确认后直接成交；资金或持仓不足会当场拦下。
- **持仓页**：每页 5 行，下方 `卖①…卖⑤` 对应本页持仓，点击进入**二次确认**（确认卖出 / 取消），
  确认后按现价整笔卖出。
- **平台限制**：最多 5 行、每行 5 个按钮、按钮文字 ≤ 10 个字符、回调数据 ≤ 1024 字节；
  超长截断、超量丢弃，不让整条消息发送失败。
- **交互回复只发文字**：QQ 官方对按钮交互的回复会忽略图片，所以按钮驱动的命令自动走文字分支。
- 需要 AstrBot >= 4.29.4（按钮组件与 `filter.button_action`）；低于此版本自动退回纯文字。
- 配置项：`interactive_buttons`（默认开）、`text_chain`（默认开）。

### 行情来源（真实行情模式，默认）

- 股票走腾讯行情 `qt.gtimg.cn`，外汇走新浪 `hq.sinajs.cn`，都是公开免 key 接口；一次请求可批量取全部品种。
- 报价在 `refresh_seconds`（默认 60 秒）内复用同一帧，避免每条指令都打接口；同一时刻多个群同时触发时只抓一次。
- 抓取失败（断网、接口变更、限流）不会阻塞交易：沿用上一帧并写一条告警日志，缓存同时落盘到 `cache/quotes.json`，重启后先读盘再刷新。
- 账本里的 `prev` 是**昨收**，所以「当日涨跌」就是真实涨跌幅；开高低也一并记录，`/股市 行情 代码` 能看今日开 / 高 / 低。
- 价格精度按品种区分：股票 2 位小数（内部整数为分），外汇 4～6 位小数（内部整数为百万分之一元），金额统一按 `price × 数量 × 100 / 精度` 换算成分，买卖共用一条公式，往返结算闭合。
- 港股 / 美股按报价数值直接以「元」记账，不做汇率换算；这样同一账户里各品种可以横向比较。
- 从老版本（纯模拟账本）升级时，账本里不在新品种表中的旧持仓会按最后价**无手续费清算**成现金并写一条提示，资产不会因为「找不到行情」凭空归零。

### 模拟模式（`data_source=simulated`）

- 行情每 `round_seconds`（默认 300 秒）推进一轮，普通波动单轮涨跌 ≤ `max_change_pct`（默认 10%）；被重大 / 黑天鹅新闻点名的股票可以突破这个上限。
- 新闻：每轮按 `news_probability`（默认 0.35）概率生成一条，分四档——**普通**（55%，±2%～4%）、**重要**（30%，±5%～8%）、**重大**（12%，±10%～15%）、**黑天鹅**（3%，±18%～30%）。`news_scope` 控制影响范围：默认 `sector` 时普通档只影响被点名的股票，重要/重大带动同板块，黑天鹅再波及全市场；设为 `stock` 则所有新闻只影响单只，设为 `market` 则所有新闻都带动全市场。跟风的股票按 `news_spillover`（默认 0.4）打折，黑天鹅波及的全市场部分再减半。
- 被新闻影响的股票，本轮上限取「`max_change_pct`」和「新闻幅度」的较大者；总上限由 `news_max_pct`（默认 30%）兜底。
- 涨跌按对数正态计算：乘数取 `exp(δ)`，δ 在 ±log(1 + `max_change_pct`) 上对称取值，长期既不会系统性阴跌，也不会一路走高。
- 股价不会跌破 `min_price`（默认 0.10 元）。
- 退市：连续 `delist_rounds`（默认 72 轮，约 6 小时）低于 `delist_price`（默认 0.50 元）即退市，挂单全撤、持仓按最后价强制平仓；停牌满 `relist_after_rounds`（默认 240 轮）自动复牌，起售价 = 退市价 × `relist_multiplier`（默认 5 倍），管理员也可用 `/股市 复牌` 提前恢复。
- 行情不依赖后台任务：轮次由时间戳推导，有指令时惰性补算，容器重启后行情仍然连续。

### 交易与玩法（两种模式共用）

- 买卖手续费各 `fee_rate`（默认 0.1%），按成交额向上取整到分，成本里包含买入手续费。
- 限价单达到限价时按**当时市价**成交（可能优于限价），冻结差额自动退回；到期未成交自动撤销。
- 价格上涨显示红色、下跌显示绿色，与 A 股习惯一致。
- **资产清零播报**：某人净资产（可用 + 冻结 + 持仓市值 − 欠款）跌到 ≤ 0 时，群里会播报
  `💥 昵称 空中飞人了！净资产 0.00 元`。每人只播一次，净值回正后再次爆仓会重新播；
  优先主动发群消息，发不出去时随当前指令的回复带出。配置项 `broke_broadcast` 可关。

### 玩法规则

- **签到**：按 UTC+8 自然日，一天一次；连续第 N 天奖励 = 基础 × (1 + (N-1)×10%)，加成封顶 50%，断签从 1 重算。
- **补助**：净资产（可用 + 冻结 + 持仓市值 − 欠款）低于补助线才能领，默认 24 小时冷却。
- **杠杆（倍数开仓）**：`/股市 融资买入 SH600519 100 2` 表示按 2 倍开仓。以 1 万元市值、2 倍为例，自有保证金 5,000 元，系统垫付 5,000 元记入欠款；手续费按整笔成交额收取，从可用资金扣。盈亏按整笔市值计算，所以本金盈亏被放大。
  - 欠款按 UTC+8 自然日计息（`margin_daily_rate`，默认 0.05%/天），利息并入欠款，不会出现负现金。
  - 逐仓权益 = 市值 − 欠款；权益/市值低于 `margin_call_ratio`（默认 25%）时自动按市价强平。2 倍杠杆大约价格跌一半才会触发（新闻和连续补算可能让它更快）。
  - 强平后如果成交额不够还清欠款，差额保留为账户欠款；签到、补助、抢劫所得、转账/发钱收入都会**优先自动还债**，还清前不能再融资买入。
  - 手动卖出杠杆持仓时按卖出股数比例偿还欠款；`/股市 还债` 可随时用可用资金提前还款。
  - 有欠款时不能继续融资，普通买入/限价单不受影响。排行榜和补助按扣掉欠款后的净资产计算。
- **盈亏榜**：盈亏 = 已实现盈亏 + 持仓浮动盈亏，只统计买卖；签到、补助、give、抢劫、db 的资金变化不计入，0 盈亏不上榜，所以它反映的是「炒股本事」而不是「谁签到多」。
- **db**：下注从可用资金扣，回报在 `0 ~ 2X` 均匀随机；下注额等于全部可用资金时按全仓规则结算——80% 拿 2X、20% 拿 0。使用系统真随机，不受行情种子影响。
- **抢劫**：只抢可用现金，目标低于 10 元不能抢；成功率 = `40 + (我的可用资金 − 对方可用资金)/500`（元为单位，**持仓市值不参与计算**，每差 500 元加减 1 个百分点），夹在 25%～75%；成功抢走 5%～20%，失败反被抢同样比例；每人每群 10 分钟冷却。
- **transfer / give / clear**：`transfer` 从自己可用资金扣、对方加，免手续费，双方都必须已开户；`give` 是管理员凭空发放，不扣发起人；`clear` 同样是管理员操作，把目标可用资金清零并撤销其挂单（冻结资金一并作废），**持仓不清**——股市资产里股票占大头，强行按市价清仓没有依据。
- **两套独立白名单**（插件配置项，**默认都是空列表**，部署后需自己填 QQ 号；与 AstrBot 的 `admins_id`、群主、群管理身份完全独立，即使对方是 AstrBot 管理员，不在名单里也不能用）：
  - `rename_admins`：只对 `/股市 改名` 生效，可以只给改名权限而不给发钱/清零权限。
  - `market_admins`：只对 `give` / `clear` 生效。
  - 哪张名单留空，对应指令就谁都用不了。
- 排行榜昵称取自群名片（指令触发时刷新），拿不到就显示 QQ 号。

## 数据与配置

- 数据：`data/plugin_data/astrbot_plugin_stock_market/groups/<群号或 private_用户>.json`（账户里额外记录昵称、签到日期/连续天数、上次补助与抢劫时间）
- 行情缓存：`data/plugin_data/astrbot_plugin_stock_market/cache/quotes.json`（最近一帧真实报价，抓取失败时兜底）
- 股票名称：`data/plugin_data/astrbot_plugin_stock_market/names.json`（**所有群共用**，`/股市 改名` 后各群下一次指令即生效；价格、账户、挂单、新闻仍按群独立）
- 渲染缓存：`data/plugin_data/astrbot_plugin_stock_market/cache/`（自动清理）
- 可选背景图：把 `bg.jpg` / `bg.png` 放进插件目录的 `assets/`，卡片会自动叠加。
- 配置项见 `_conf_schema.json`，可在 AstrBot 的插件配置页直接改。真实行情相关：`data_source`（real / simulated）、`refresh_seconds`、`alert_moves_pct`、`symbols`、`fx_enabled`、`fx_pairs`、`quote_timeout`；消息交互相关：`interactive_buttons`、`text_chain`、`broke_broadcast`。

## AI 辅助创作说明

本插件是 AI 辅助创作的产物，具体情况如下：

- **需求与验收**：玩法设计、功能取舍、数值规则（手续费、签到加成、抢劫概率等）以及线上部署，均由作者决定并逐项验收。
- **代码与文档**：在 AI 编程助手（Claude，Anthropic）协助下编写，生成后经作者审查、修改与测试。
- **测试情况**：引擎层 57 项单元测试（`python tests/test_engine.py`）、行情与外汇 18 项（`python tests/test_feeds.py`）、消息交互 9 项（`python tests/test_interactive.py`）以及容器内冒烟测试均通过；作者在自建 AstrBot（QQ / aiocqhttp 适配器）实例上实际运行。
- **已知局限**：只在 aiocqhttp 适配器上验证过，其他平台未测试；卡片渲染依赖系统中文字体（内置 Noto / 微软雅黑 / 苹方回退）。
- **风险提示**：AI 生成的代码可能存在未覆盖的边界情况，建议先在小群试用；发现问题欢迎提 issue。
- **真实行情依赖**：股票报价来自腾讯 `qt.gtimg.cn`，外汇来自新浪 `hq.sinajs.cn`，均为公开接口，可能限流、改字段或因网络不可达而失败；失败时插件沿用上一帧报价并在日志里告警，不会让交易崩掉。

本插件全部为虚拟货币玩法，与真实证券交易无关，不构成任何投资建议。
